## Rodar localmente

**Pré-requisitos:** Node.js e o backend da Vencar em execução.

1. Instale as dependências: `npm install`
2. Copie `.env.example` para `.env.local` e ajuste `VITE_API_URL` e `VITE_API_TOKEN`, se precisar
3. Rode o app: `npm run dev` (porta 3000, a origem liberada no CORS do backend)
